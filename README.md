# OLA Ride Booking Analysis | SQL & Power BI

## Project Overview

This project analyzes OLA ride booking data to identify patterns in bookings, revenue, vehicle performance, customer behavior, cancellations, and operational performance.

The analysis was performed using **SQL** for data querying and analysis, and **Power BI** for interactive dashboard creation and visualization.

## Tools & Technologies

* **SQL** – Data querying, analysis, views, aggregations, and performance metrics
* **Power BI** – Interactive dashboards and data visualization
* **DAX** – KPI calculations and dashboard measures
* **GitHub** – Project documentation and version control

## Key KPIs

| KPI                     |    Value |
| ----------------------- | -------: |
| Total Bookings          |     100K |
| Successful Rides        |      62K |
| Total Revenue           |      14M |
| Cancellation Rate       |     0.38 |
| Average Ride Distance   | 15.54 KM |
| Average Customer Rating |     4.00 |

## SQL Analysis

The project includes analysis for:

1. Successful bookings
2. Average ride distance by vehicle type
3. Customer cancellations
4. Top customers by number of rides
5. Driver cancellations
6. Driver ratings
7. Customer ratings by vehicle type
8. Successful booking revenue
9. Incomplete rides and reasons
10. Booking status distribution
11. Revenue by booking status
12. Cancellation reasons and revenue at risk
13. Pickup location failure rate
14. Revenue contribution by vehicle type
15. Top customers by revenue
16. Vehicle cancellation and failure rates

## Power BI Dashboard

The dashboard provides analysis of:

* Booking and revenue performance
* Vehicle type performance
* Customer behavior
* Customer and driver cancellations
* Incomplete ride reasons
* Pickup location failure rates
* Revenue and booking trends over time
